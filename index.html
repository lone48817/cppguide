1. Bitwise Operations

Bitwise operations work directly on the binary form of numbers. They allow manipulation of individual bits instead of whole values. These operations are widely used in optimization, system programming, and efficient calculations.
2. Binary Numbers
2.1 Concept of Binary

Binary numbers use only two digits: 0 and 1. Each position represents a power of 2 starting from the right. The decimal value is found by adding powers of 2 where bits are 1.

Bit position: 7 6 5 4 3 2 1 0
Value: 128 64 32 16 8 4 2 1

📦 STRUCTURES (struct)

Group different data types into one custom unit — model real-world objects like products, students, cars, and books.
1. What Is a struct?

In C++, a structure (struct) lets you group different pieces of data together under one name. You can think of it like a custom data type that you design yourself.

A struct is used to combine multiple variables of different types into one single unit. It helps represent real-world objects like products, students, cars, or books. It improves readability and organizes data efficiently.

A struct does not perform actions like functions. It only stores data. Each variable inside a struct is called a member.

2. Syntax of struct
struct TypeName {
member_type1 member_name1;
member_type2 member_name2;
};
•TypeName → name of structure
•Members → variables inside structure
•Different data types allowed
•Ends with semicolon

⚡ BIT MANIPULATION TRICKS (C++)

Work directly with individual bits — faster operations, competitive programming, and low-level optimization.
1. Introduction to Bit Manipulation Tricks

Bit manipulation tricks are techniques used to work directly with individual bits of a number. These tricks make programs faster and more efficient compared to normal arithmetic operations. They are widely used in competitive programming and system-level coding.

We assume:

  • int x → non-negative integer
  • int k → bit index (0-based, 0 = least significant bit)

We use masks like (1 << k) where only bit k is 1.

2. Checking if a Bit is 1

Concept
We check whether a specific bit is ON (1) or OFF (0). This is useful in feature flags, permissions, and binary states.

Formula: bool isSet = (x >> k) & 1;
•x >> k → moves k-th bit to rightmost position
•& 1 → extracts only last bit
•result is 0 or 1 (false or true)
Example
x = 10 → 1010
Check k = 1
Result = 1 (bit is set)
📄 C++ Program
#include <iostream>
using namespace std;

bool kthBitIsSet(int n, int k) {
    return (n >> k) & 1;
}

int main() {
    int n = 10;
    int k = 1;

    cout << kthBitIsSet(n, k);
}
Step-by-Step Explanation
1include library → enables input/output
2define function → checks k-th bit
3n >> k → shifts bit to right
4& 1 → extracts bit
5main() starts execution
6n = 10 (binary 1010)
7k = 1 checks second bit
8output = 1 (true)

🎯 GENERATING SUBSETS USING BITMASKS (C++)

Represent subsets using binary numbers — efficient, fast, and perfect for combinatorics problems.
1. What is a Subset?

A subset of a sequence is a set that contains some or all elements of the original sequence. It can also contain no elements (empty set).

For example, for the sequence {1, 3, 5, 6, 7}:

  • Valid subsets: {1, 3}, {3, 5, 7}, {1, 3, 5, 6, 7}, {}
  • Invalid subsets: {1, 4}, {2, 7} (because elements are not in original sequence)

A subset is formed only from existing elements of the original set.

2. Idea of Bitmasking

Bitmasking is a technique where we use binary numbers to represent subsets.

Each element is represented by a bit:

  • 1 → element is included in subset
  • 0 → element is not included

This allows us to represent all subsets using numbers from 0 to (2^n - 1).

3. Encoding Subsets as Binary Numbers

For a sequence of length n, we use an n-bit binary number.

Each bit represents whether an element is included or not.

Example: {5, 3, 1}
| Subset | Binary | Decimal | | --------- | ------ | ------- | | {} | 000 | 0 | | {5} | 001 | 1 | | {3} | 010 | 2 | | {5, 3} | 011 | 3 | | {1} | 100 | 4 | | {5, 1} | 101 | 5 | | {3, 1} | 110 | 6 | | {5, 3, 1} | 111 | 7 |
🔑For a sequence of length n: Total subsets = 2^n | Range of masks = 0 to (1 << n) - 1
4. Generating All Subsets (Main Idea)

We loop through all numbers from 0 to (2^n - 1). Each number represents one subset.

For each number, we check each bit:

  • If bit is 1 → include element
  • If bit is 0 → ignore element
5. BASIC C++ PROGRAM (Given Example)

GOAL
Understand how bitmasks generate all subsets step-by-step.

📄 C++ PROGRAM
#include <iostream>
using namespace std;

int main() {
    int n = 3;
    int a[3] = {5, 3, 1};

    for(int i = 0; i < (1 << n); i++) {
        cout << i << ": ";

        for(int j = 0; j < n; j++) {
            bool set = (i & (1 << j)) != 0;

            if(set) {
                cout << a[j] << ' ';
            }
        }

        cout << endl;
    }
}
STEP-BY-STEP EXPLANATION
1#include <iostream> → Adds input/output support, Enables cout
2using namespace std → Avoids std:: prefix, Simplifies code
3int n = 3 → Size of array, 3 elements in sequence
4int a[3] → Array stores values {5, 3, 1}
5Outer loop: for(int i = 0; i < (1 << n); i++) → (1 << n) = 2^n = 8, Loop from 0 to 7, Each i represents a subset
6Print i → Shows subset number
7Inner loop: for(int j = 0; j < n; j++) → Checks each bit position
8Bit check: bool set = (i & (1 << j)) != 0; → Checks if j-th bit is ON, If yes → include element
9if condition → If bit is set → print a[j]
10End line → Moves to next subset

🔄 BACKTRACKING (C++) – FULL GUIDE

Explore all possible solutions by building step by step and undoing choices when needed — perfect for subsets, permutations, puzzles, and optimization.
1. What is Backtracking?

Backtracking is a problem-solving technique that explores all possible solutions. It builds solutions step by step and removes (undoes) choices when they are no longer needed.

It is used when we need to try all combinations or possibilities. It is commonly used in recursion-based problems. Examples include subsets, permutations, puzzles, and optimization problems.

Backtracking is like trying paths in a maze. If one path fails, we go back and try another.

2. How Backtracking Works

Backtracking follows these steps:

1Start with an empty solution
2Add one element (choice)
3Recursively explore further
4Undo the last choice (backtrack)
5Try next possibility

This ensures all possibilities are explored.

3. Generating Subsets using Backtracking

Concept
To generate all subsets:

  • For each element, we have 2 choices: Include it or Exclude it

This creates a recursion tree.

4. GIVEN PROGRAM (Subsets)
📄 C++ PROGRAM
#include <iostream>
#include <vector>

using namespace std;

int n = 3;
int a[3] = {5, 3, 1};
vector<int> v;

void backtracking(int i) {

    // if i == n, all the elements are considered, print the current subset
    if (i == n) {
        cout << "subset: ";
        for (int j = 0; j < v.size(); j++) {
            cout << v[j] << ' ';
        }
        cout << "\n";
        return;
    }

    // try when a[i] is included
    v.push_back(a[i]);
    backtracking(i + 1);

    // try when a[i] is excluded
    v.pop_back();
    backtracking(i + 1);
}

int main() {
    backtracking(0);
}
STEP-BY-STEP EXPLANATION
1Global variables: n = 3 → size of array, a[] → stores values {5,3,1}, vector v → stores current subset
2Function backtracking(i) → i represents current index, recursion explores all choices
3Base condition: if(i == n) → all elements processed, print current subset, return
4Include element: v.push_back(a[i]) → add element, explore further
5Recursive call: backtracking(i+1) → move to next index
6Undo step: v.pop_back() → remove last element, backtrack
7Exclude element: call backtracking(i+1) → explore without element

7. Example Problem: Apple Division

PROBLEM
Divide array into 2 groups such that difference of sums is minimum.

📄 GIVEN PROGRAM
#include <iostream>

using namespace std;

int n;
int a[20];
long long sum1 = 0;
long long sum2 = 0;
long long ans = 2000000000;

void backtracking(int i) {
    if (i == n) {
        ans = min(ans, abs(sum1 - sum2));
        return;
    }

    sum1 += a[i];
    backtracking(i + 1);
    sum1 -= a[i];

    sum2 += a[i];
    backtracking(i + 1);
    sum2 -= a[i];
}

int main() {

    cin >> n;

    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    backtracking(0);

    cout << ans << "\n";
}
STEP-BY-STEP EXPLANATION
1Input: n → number of elements, array a stores values
2Variables: sum1 → group1 sum, sum2 → group2 sum, ans → minimum difference
3Base case: if(i == n) → all elements assigned, calculate difference, update answer
4Choice 1: add element to sum1, explore, undo (subtract)
5Choice 2: add element to sum2, explore, undo
6Output: print minimum difference
